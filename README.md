# MeowDoku

MeowDoku is a planned offline mobile logic puzzle game for Android and iOS.
The first release is specified in [the MVP design](docs/superpowers/specs/2026-10-17-meowdoku-mvp-design.md). Implementation has not started.

The repository currently contains planning documents only. [The app schema](docs/app-schema.md) defines screen and data boundaries, and [the ticket index](codex/tickets/README.md) orders the implementation work. No app has been built or verified yet.
