# MeowDoku mobile

Flutter app shell for the MeowDoku project. It currently contains Home, Difficulty, Puzzle, and Settings placeholders. Puzzle logic and saved progress are planned in later tickets.

Resolve dependencies with `flutter pub get`, then run `./tool/verify.sh` for formatting, analysis, and widget tests. If Flutter is not on your `PATH`, set `FLUTTER_BIN` to the installed Flutter executable before running the script.
