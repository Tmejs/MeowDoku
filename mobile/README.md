# MeowDoku mobile

Flutter app shell for the MeowDoku project. It contains Home, Difficulty, Puzzle, and Settings placeholders plus the bundled 100-board pack and pure puzzle rules. Gameplay and saved progress are planned in later tickets.

Resolve dependencies with `flutter pub get`, then run `./tool/verify.sh` for formatting, analysis, Flutter tests, Python pack tests, and the pack audit. If Flutter is not on your `PATH`, set `FLUTTER_BIN` to the installed Flutter executable before running the script.
